## 6. TRAPS — each of these was paid for

- **`execute_blender_code`-style single-shot thinking does not transfer.** Here: a `replace`
  anchored on `def dispatcher_for(` silently edited `loop.py` instead of `runtime.py`, and the
  call sites landed with no definition. Always check the anchor is *unique to the file you mean*.
- **A heredoc `<<'PY'` with `"\n".join(...)` inside a replacement string** produces a real newline
  and a `SyntaxError: unterminated string literal`. Write it as `"\n".join(...)` or use `edit`.
- **A dataclass field added without the `cls(...)` argument** gives a late, confusing
  `unexpected keyword argument` at construction — not at definition. Add both together.
- **Producer allow-lists are closed.** `definition.created` rejected `JACK_THE_SPLITTER` — and
  correctly so. The loop authors splits, so `manager` was added. Do not borrow another role's
  authority to make a call pass.
- **The provider is flaky** — "Provider returned an empty response" recurs. Nudge policy exists
  and is not fully integrated into the split flow. This is an *outside* failure: build code to
  deal with it, do not test around it.
- **Never write code to test code.** Verification here = run it, read the output, delete nothing
  because nothing was kept.
